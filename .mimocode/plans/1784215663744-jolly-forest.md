# Plan: Editor de Landing Page Nivel Shopify Avanzado

## Resumen

Mejorar el editor de landing page del producto en el WMS para que sea un editor profesional nivel Shopify. Incluye: fix de imágenes, editor de texto rico, galería completa, responsive, drag-and-drop real, undo/redo, templates, SEO, publicación programada, analytics, y control total de personalización.

---

## FASE 0: Fix de Imágenes (CRÍTICO)

**Problema**: Las imágenes no se guardan al editar un producto.

**Causa probable**: El campo `mainImageIndex` no existe en la BD (solo en estado React). Al guardar, se envía pero no se persiste. También puede haber un problema con el array `images` en el PUT.

**Archivos a revisar:**
- `wms/src/app/api/v1/products/[id]/route.ts` — verificar que el PUT recibe y guarda `images`
- `wms/src/components/catalogo/ProductForm.tsx` — verificar que `handleSave` envía `images`
- `wms/src/app/(dashboard)/catalogo/page.tsx` — verificar `startEdit` carga imágenes correctamente

**Fix:**
1. Agregar columna `main_image_index` a la BD (o usar siempre índice 0)
2. Verificar que el PUT handler recibe `images` y lo guarda
3. Verificar que `startEdit` mapea `product.images` → `productImages` correctamente

## FASE 1: Editor de Texto Rico

**Replacing**: textarea plano en bloques de texto/descripción

**Solución**: Integrar un editor WYSIWYG ligero. Opciones:
- **TinyMCE** (free tier, rich features)
- **Tiptap** (headless, más flexible, mejor para React)
- **Quill** (ligero, open source)

**Recomendación**: **Tiptap** — es headless, se integra bien con React, soporta: bold, italic, underline, listas ordenadas/no ordenadas, links, imágenes inline, headings, blockquotes, código.

**Archivos a modificar:**
- `wms/src/components/catalogo/landing/blocks/TextBlockEditor.tsx` (CREAR o reemplazar textarea)
- `wms/src/components/catalogo/tabs/InfoTab.tsx` — reemplazar textarea de descripción
- `packages/prisma-wms/schema.prisma` — campo `description` cambia de `String?` a `Text` (soporte HTML)
- `tienda/src/app/(public)/producto/[slug]/page.tsx` — renderizar HTML con `dangerouslySetInnerHTML` + DOMPurify

**Bloques afectados:**
- `text` block: heading + body con editor rico
- `features` block: descripción de cada feature con editor rico
- `testimonials` block: cita con formato
- `faq` block: respuesta con editor rico
- `accordion` block: contenido con editor rico
- `columns` block: contenido de cada columna con editor rico

## FASE 5: Undo/Redo + Atajos de Teclado

### 5.1 — Undo/Redo

**Implementación**: Historial de estados en el `ProductFormContext`.

```
history: LandingPageBlock[][]  // array de snapshots
historyIndex: number           // posición actual
```

- Cada cambio de bloques crea un snapshot
- Ctrl+Z: retroceder en historial
- Ctrl+Shift+Z o Ctrl+Y: avanzar
- Límite de 50 snapshots

### 5.2 — Atajos de Teclado

| Atajo | Acción |
|-------|--------|
| Ctrl+Z | Undo |
| Ctrl+Shift+Z | Redo |
| Ctrl+D | Duplicar bloque seleccionado |
| Ctrl+S | Guardar producto |
| Delete | Eliminar bloque seleccionado |
| Ctrl+Shift+P | Toggle preview |
| Escape | Cerrar modales |

## FASE 9: Publicación

### 9.1 — Estados de publicación

| Estado | Descripción |
|--------|-------------|
| `draft` | Borrador, no visible en tienda |
| `active` | Publicado, visible en tienda |
| `scheduled` | Programado para fecha futura |
| `archived` | Archivado, no visible |

### 9.2 — Programar publicación

Campo `publishedAt` (ya existe en schema) — si tiene fecha futura, el producto no se muestra hasta esa fecha.

**Implementación:**
- En InfoTab o en el botón de publicar: datepicker para programar
- Cron job o check en el storefront: si `publishedAt > now()`, no mostrar

### 9.3 — Preview antes de publicar

Botón "Vista previa" que abre la página del producto en la tienda con un token temporal (sin necesidad de estar publicado).

**Implementación:**
- Route: `/preview/[token]` que muestra el producto sin importar status
- Token: JWT firmado con el ID del producto, expira en 1h

### 9.4 — Historial de cambios + Rollback

El sistema de versiones ya existe (`ProductVersion` model). Mejorar:
- Mostrar diff visual entre versiones
- Botón "Restaurar esta versión" más visible
- Notificación de cambios sin guardar

**Archivos:**
